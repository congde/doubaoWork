# 思维导图与章节技能

本资源与《豆包工作14天玩转AI办公》当前15章对应，包括1张全书导图、15张章节导图及15个独立技能。各章正文已收录完整技能规则和教学输入，不依赖外部下载页面。

## 直接开始

双击[打开这里.html](打开这里.html)，选择任务后即可复制完整示例。要处理自己的材料，切换到“用我的材料”，填写内容后复制完整指令。页面支持单章下载，可以离线使用。

## WPS 与 MindLine 的格式选择

用户指定的使用软件是 WPS、MindLine。本次核对到 MindLine 在线版的文件选择器接受 `.mm,.xmind`，其原生 `.mm` 是带节点类型的 JSON；它与 FreeMind 同名扩展的 XML 文件不是同一种文件。因此，本包不把文件伪装为 `.mind`。

- **MindLine**：优先打开“MindLine原生”文件夹中的16个 `.mm` 文件，保留左右分支。也可导入交换版 `.xmind`。
- **WPS**：使用“WPS与通用交换”文件夹中的16个 `.xmind` 文件，在实际版本的思维导图组件中导入。部分版本入口为“应用市场—文档处理—本地思维导图—文件—导入”；普通WPS文字窗口未必能直接打开。
- **书稿插图**：PNG保留在mindmaps中，便于排版；其节点文字与可编辑文件对应。

格式依据：[MindLine官方使用说明](https://www.mindline.cn/UseGuidePC.html)、[MindLine官方程序文件](http://www.mindline.cn/webapp/webapp-a.js)、[MindLine官方XMind转换程序](http://www.mindline.cn/webapp/webapp-b.js)。WPS导入入口参考[官方社区的版本反馈](https://bbs.wps.cn/topic/84775)，其中也记录了部分版本的兼容问题，不能据此保证所有WPS版本均可导入。

本次完成文件结构与节点往返检查；浏览器编辑器访问超时，尚未完成WPS、MindLine客户端实际打开验收。请勿将此状态解读为两端已实测兼容。

## 怎样使用

1. 先从下表选择当前任务对应的章节，阅读导图，明确任务在本章中的位置。
2. 打开技能文件，将完整内容作为工作方法交给支持读取Markdown的AI；也可以直接复制书内的技能规则，再粘贴试用输入。
3. 支持自定义技能的目标平台应按其实际入口录入规则；本资源不宣称豆包工作支持直接导入SKILL.md或ZIP。独立文件用于保存、分享和迁移方法。
4. 先用正常输入核对结果，再做边界和失败检查；通过自己的试跑后，再替换为允许使用的真实材料。

没有文件、联网或调度工具时，可以完成文本及离线样本练习，但不能把页面脚本称为PPT成品、把快照比较称为已创建定时任务。

## 验证边界

技能附有正常、边界和失败样本及预期行为。文件结构检查不能代替实际模型试跑；本包尚未在豆包工作客户端验证技能导入、文件生成、连接器或自动化执行。当前书稿修改以Markdown为准，此前Word导出未包含本轮增补。
