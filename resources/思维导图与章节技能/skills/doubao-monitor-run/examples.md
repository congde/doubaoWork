# 竞品更新监控单次执行：试用样本

以下均为无敏感信息的教学样本。使用时先加载同目录的SKILL.md，再提交输入；预期结果用于人工核对，不代表已经在目标平台试跑。

## 正常样本

虚构来源，窗口2026年9月1日至8日，Asia/Shanghai。只关注功能增删。A上次：支持文本导出；本次：支持文本导出和表格导出。B上次：支持搜索；本次读取失败。已有运行记录为空。请执行一次比较，不发送。

## 预期核对点

A新增表格导出；B读取失败，整体部分完成；B的上次快照保留。输出待确认摘要，不能宣称B无更新或已经设置定时任务。

## 边界样本

移除A上次快照：A为首次建档，表格导出不能算已证实的新增功能。

## 失败样本

A、B本次均读取失败：输出运行失败和恢复所需信息，不生成没有更新的报告。
