# 项目周报校验：试用样本

以下均为无敏感信息的教学样本。使用时先加载同目录的SKILL.md，再提交输入；预期结果用于人工核对，不代表已经在目标平台试跑。

## 正常样本

项目P，2026年9月1日至7日。纪要S1：本周完成模板整理，下周由林青在9月10日前补两份样本。任务表S2：T01模板整理，已完成；T02补两份样本，林青，9月10日，未开始。指标表S3：本周完成任务数1。请生成周报初稿并校验。

## 预期核对点

已完成为模板整理，完成任务数1；下周计划只列已有T02承诺；引用S1、S2、S3；不把下周样本算成本周完成任务。

## 边界样本

删去S2：指出缺少任务清单，输出部分事实与待补材料，不能宣称完整校验通过。

## 失败样本

将S3改为完成任务数3：报告与任务清单的1项冲突，不能择一生成无保留结论。
