# 豆包工作功能详解

核对日期：2026-09-08。34项能力与入口，14项资料。功能概述依据所列资料；任务示例、材料准备和检查条件由本页编写，未经本次产品实测。

## 文档与演示

### 方案与报告写作

发布报道

**功能概述**：根据已有材料生成或修改工作文档。

**输入材料**：事实材料、读者、篇幅、需要回答的问题

**交付物**：方案、报告、说明文档

**使用条件**：材料不足的结论需要补证；正式文件应打开检查。

**任务示例（本页设计）**：把三份项目记录整理成一份复盘，结论后注明来自哪份记录。

资料：[IT之家：产品发布（08-25）](https://www.ithome.com/0/993/865.htm)

### 会议纪要与行动项

发布报道

**功能概述**：把会议材料整理为工作纪要。

**输入材料**：会议文字记录、日期、参会信息

**交付物**：纪要、决议与待办清单

**使用条件**：纪要整理不等于已获得录音转写工具；负责人和日期不能猜。

**任务示例（本页设计）**：按已决定、待讨论、待执行三类整理这份记录，缺少负责人则标为待确认。

资料：[IT之家：产品发布（08-25）](https://www.ithome.com/0/993/865.htm)

### PPT生成与修改

官方说明

**功能概述**：制作演示文稿，承接已有资料或分析。

**输入材料**：汇报目标、听众、时长、依据材料

**交付物**：可继续修改的PPT

**使用条件**：先确认内容结构，再检查页数、图表和排版；不承诺任意模板完全还原。

**任务示例（本页设计）**：依据季度数据做8分钟汇报，先给逐页观点，再制作演示稿。

资料：[飞行社：亮点功能培训](https://www.feishu.cn/community/course?id=7661849741298240446&tab=course)

### 局部定向编辑

发布报道

**功能概述**：对生成文件的指定部分提出修改。

**输入材料**：已有产物、选定区域、修改要求

**交付物**：局部更新的文档、表格、PPT或网页

**使用条件**：对象是否可框选以实际编辑器为准；修改后仍要检查关联数字。

**任务示例（本页设计）**：只改第三页结论和对应图例，保留其他页面结构。

## 组合场景（本页设计）

### 行业调研 → 报告 → 汇报

输入：研究范围、企业名单、比较维度

过程：公开检索与多份资料阅读 → 按对象并行取证，再统一比较 → 形成报告、图表与PPT

交付：有来源的比较表、研究报告、汇报稿

检查：关键数字回到原始来源；不同交付物口径一致。

### 会议材料 → 行动清单 → 团队协作

输入：会议文字记录、现有台账、确认的决议

过程：提取决议与行动项 → 核对责任人、日期和重复项 → 将确认成果交回飞书

交付：纪要、行动表与待确认清单

检查：建议不写成决议，未授权时只提供草稿与链接。

### 订单数据 → 清洗分析 → 周期复盘

输入：数据表、统计口径、原始版本

过程：整理字段与异常数据 → 复算指标并制作图表 → 验证后再配置周期执行

交付：清洗表、指标图表、周期报告

检查：先完成一次人工核验，再检查调度环境与下次运行时间。

### 活动资料 → 图片视频 → 展示页面

输入：活动事实、品牌素材、发布渠道要求

过程：统一文案与视觉要求 → 制作图片及视频素材 → 汇成网页并检查交互

交付：活动素材与展示页面

检查：所有渠道的日期、价格与报名信息一致；发布需另行确认。

项目历史拖入、技能包导入格式、连接器完整名单与动作、云环境限额、网站数据库当前开放范围、网页手机端功能一致性仍需实际版本核对。未将这些条件写成全量支持。
