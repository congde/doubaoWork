# 竞品更新监控单次执行

版本：1.0

## 使用范围

比较指定来源的本次与上次快照，输出有证据的变化、来源失败和状态记录。用于定时监控中的一次运行。

## 开始使用

收到任务后先检查用户已经给出的材料。材料足够时直接按本技能完成，不要求用户重新填表或逐步确认。缺少会影响结果的关键信息时，一次集中询问；其他缺项标为待确认并继续可完成的部分。用户未指定格式时，先交付便于复制的中文文本或表格。示例输入只用于试用，处理用户真实材料时不得混入示例事实。

## 输入材料

提供来源标识、比较窗口与时区、上次快照、本次快照或读取失败状态、重要变化规则和已有运行记录。

## 执行方法

1. 核对来源身份与快照覆盖；缺少历史快照的来源只建立基线，不称为新增变化。
2. 按重要变化规则比较内容，分开写原文事实与影响待判断；用来源标识、条目标识和本次内容识别已报告条目。
3. 逐来源记录有变化、无变化、读取失败或首次建档；失败来源保留上次成功快照，不能用空内容覆盖。
4. 有重要变化时形成待确认摘要；全部读取成功且无变化时仅保存运行记录，不发送例行通知；部分失败时说明覆盖缺口，按用户既定规则通知。

## 交付结果

变化清单（来源、旧值、新值、证据）；逐来源状态；待确认摘要或无变化运行记录；下次比较所需的成功快照。

## 验收与停止条件

不得把读取失败写成无变化；不得声称已创建定时任务，除非调度工具返回成功记录；本技能不默认外发摘要。

## 工具条件

快照比较可离线执行；持续采集、定时触发和通知需要相应工具与授权。

## 试用与复测

需要试用或修改规则时，使用[试用样本](examples.md)中的正常、边界和失败输入，分别核对预期行为。
