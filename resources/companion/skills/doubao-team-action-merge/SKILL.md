# 团队行动项增量整理

版本：1.0

## 使用范围

将项目会议与聊天中的已确认行动合并到现有台账草稿，保留来源、版本与冲突。用于飞书等团队上下文的只读整理。

## 开始使用

收到任务后先检查用户已经给出的材料。材料足够时直接按本技能完成，不要求用户重新填表或逐步确认。缺少会影响结果的关键信息时，一次集中询问；其他缺项标为待确认并继续可完成的部分。用户未指定格式时，先交付便于复制的中文文本或表格。示例输入只用于试用，处理用户真实材料时不得混入示例事实。

## 输入材料

提供项目标识、资料时间范围、新会议或聊天摘录，以及已有行动台账；各材料保留来源编号。

## 执行方法

1. 核对项目和时间范围，列出实际可用来源；不能访问的资料单列，不以文档标题推断内容。
2. 从明确承诺中提取事项、负责人和期限；含糊讨论不自动升级为行动承诺。
3. 优先按行动编号匹配，缺少编号时比较项目、事项和来源，存在歧义则待确认；已匹配事项形成更新而不是重复新增。
4. 生成新增、更新、冲突和保留项清单；没有写回授权时交付草稿，有授权时核对目标对象并凭真实回执报告写入结果。

## 交付结果

来源表；合并后的行动台账草稿；逐项变更记录（原值、新值、依据）；冲突与待确认事项。

## 验收与停止条件

新日期必须有明确决定依据；旧版本保留替代关系；读取权限不自动包含写入或发送权限；不能把草稿称为飞书已更新。

## 工具条件

可直接合并粘贴或导出的资料；飞书读取与写回需连接器和相应范围授权。

## 试用与复测

需要试用或修改规则时，使用[试用样本](examples.md)中的正常、边界和失败输入，分别核对预期行为。
