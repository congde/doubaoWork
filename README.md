# 豆包工作 · 读者配套资源

《豆包工作：AI智能办公实战手册》及相关文章的附件下载入口。这里提供离线 HTML、章节技能、示例和可编辑思维导图。

固定地址：<https://github.com/congde/doubaoWork>

## 下载后怎样打开

1. 在仓库页面点击 **Code → Download ZIP**，下载并解压整个压缩包。
2. 根据下表找到对应文件夹，双击其中的 HTML 文件，用浏览器打开。
3. HTML 与同目录的配套文件请一起保留，避免下载、图片或导航链接失效。

GitHub 文件页面用于查看源文件；直接点击仓库中的 HTML 通常显示源码。请下载后打开。本仓库目前采用文件下载方式提供资源。

## 使用说明

- 先用提供的示例理解任务和核对方法，再换成允许使用的自己的材料。
- 技能文件用于保存和复用任务规则；是否支持直接导入技能或 ZIP，以使用平台的实际入口为准，也可复制规则使用。
- XMind、MindLine、WPS 等客户端的导入兼容性需按实际版本确认。现有结构检查不代表已完成客户端运行验收。
- 产品功能、入口和资料日期请查看各资源内的说明与来源；资源包中的历史说明不代表当前产品承诺。
